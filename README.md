Entry for the [make.fun bounty "The 3 AM Excuse"](https://make.fun/bounty/u-hazel-walrus-38-4764-the-3-am-excuse-c1017878): the most creative excuse a hardware wallet gives for refusing to sign a transaction at 3 AM.

## What it does

`main.py` (stdlib only, no third-party imports) writes one single-line excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
